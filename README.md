# نظام أسرة البابا كيرلس – خامسة ابتدائي

دليل تشغيل كامل خطوة بخطوة، حتى لو أول مرة تعمل حاجة زي كده.

---

## الجزء الأول: تجهيز قاعدة البيانات (Firebase) — مجانًا

### 1) إنشاء المشروع
1. روح على https://console.firebase.google.com
2. سجّل دخول بحساب Google بتاعك.
3. اضغط **"Add project" / إضافة مشروع**.
4. اكتب اسم زي `kyrillos-family` واضغط Continue.
5. تقدر تعطّل Google Analytics (مش لازم)، واضغط **Create project**.

### 2) تفعيل تسجيل الدخول
1. من القائمة الجانبية اليسار: **Build > Authentication**.
2. اضغط **Get started**.
3. من تبويب **Sign-in method**، اختار **Email/Password** وفعّله (Enable) واحفظ.

### 3) إنشاء قاعدة البيانات
1. من القائمة الجانبية: **Build > Firestore Database**.
2. اضغط **Create database**.
3. اختار **Start in production mode** ثم Next.
4. اختار أقرب موقع سيرفر (مثلاً `eur3` لو في أوروبا/مصر) واضغط **Enable**.
5. بعد ما تتفتح، روح تبويب **Rules** وامسح اللي موجود، والصق بدله محتوى ملف `firestore.rules` الموجود في المشروع، واضغط **Publish**.

> **ملاحظة:** صور المخدومين بتتخزن مباشرة جوه قاعدة البيانات Firestore نفسها (كصورة مضغوطة صغيرة)، فمش محتاجين خدمة Storage المنفصلة خالص — ده بيوفّر عليك خطوة تفعيل حساب فوترة (Blaze) اللي Google بقت تطلبها لخدمة Storage.

### 4) الحصول على مفاتيح الربط
1. من القائمة الجانبية اضغط على أيقونة الترس ⚙️ بجانب **Project Overview** ثم **Project settings**.
2. انزل لقسم **Your apps**، اضغط أيقونة **</>** (Web).
3. اكتب اسم للتطبيق مثل `kyrillos-web` واضغط **Register app**.
4. هتظهرلك قيم زي دي، خدها كلها:
   ```
   apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId
   ```
5. افتح ملف `.env.example` الموجود في المشروع، اعمل نسخة منه واسمها `.env`، وحط كل قيمة في مكانها بعد علامة `=`.

## الجزء الثاني: تشغيل المشروع على جهازك

### 1) تثبيت Node.js (لو مش مثبت)
- روح https://nodejs.org وحمّل النسخة **LTS** ونزّلها عادي زي أي برنامج.

### 2) تثبيت المكتبات
افتح Terminal / Command Prompt جوه مجلد المشروع واكتب:
```
npm install
```

### 3) التشغيل التجريبي على جهازك
```
npm run dev
```
هيديك رابط زي `http://localhost:5173` — افتحه في المتصفح وجرّب.

**أول حاجة اعملها:** اضغط "سجّل حساب جديد" وسجّل بياناتك — هتبقى تلقائيًا "مسؤول" لأنك أول حد.

## الجزء الثالث: نشر الموقع عشان الخدام يستخدموه من أي مكان

أسهل طريقة من غير سطر أوامر معقد: **Vercel** (مجاني).

### 1) رفع المشروع على GitHub
1. اعمل حساب على https://github.com لو مالكش.
2. اضغط **New repository**، اكتب اسم زي `kyrillos-family-system`، واضغط **Create repository**.
3. ارفع كل ملفات المشروع (فيه زرار **uploading an existing file** في صفحة الـ repo، تقدر تسحب كل الملفات والمجلدات وتفلتها).
   - **مهم:** متسيبش ملف `.env` يترفع (فيه بياناتك السرية)؛ سيبه بس محلي عندك.

### 2) الربط مع Vercel
1. روح https://vercel.com وسجّل دخول بحساب GitHub بتاعك.
2. اضغط **Add New > Project**.
3. اختار الـ repository اللي رفعته.
4. في خانة **Environment Variables**، ضيف نفس القيم اللي في ملف `.env` بتاعك (كل اسم وقيمته).
5. اضغط **Deploy**.
6. بعد شوية هتاخد رابط زي `kyrillos-family-system.vercel.app` — ده رابط الموقع النهائي، ابعته للخدام.

## ملاحظات مهمة

- **الأمان حقيقي**: قواعد Firestore (`firestore.rules`) بتتأكد من صلاحية كل مستخدم على مستوى السيرفر نفسه، مش بس بإخفاء الأزرار في الواجهة.
- **أول مستخدم يسجل = مسؤول تلقائيًا**، وبعد كده المسؤول يقدر يرفّع أو يخفّض أي خادم من صفحة "المستخدمون" داخل النظام.
- **حذف مستخدم نهائيًا** (منع دخوله بالكامل) لازم يتعمل يدويًا من Firebase Console: **Authentication > Users**، اختار المستخدم واضغط حذف. تخفيضه لـ"خادم" من داخل النظام كافي في أغلب الحالات.
- لو حسيت إن أي خطوة معقدة أو ظهر خطأ، ابعتلي لقطة شاشة (screenshot) وهساعدك تحلها.
